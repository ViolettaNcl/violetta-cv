# Violetta Nicolaou — Full-Stack Developer

Interactive business-card site and portfolio: web apps, mobile apps, APIs and bots — from idea to launch and support.

## Live site

[violetta-cv.vercel.app](https://violetta-cv.vercel.app)

## What's inside

- **3D particle field** (Three.js) that morphs between shapes as you scroll — a halo around the avatar, a knot, `</>`, `{ }`, `@` and a heart after a message is sent
- **Services** — web apps, mobile apps, APIs & integrations, bots & automation, websites & landing pages, games & interactive
- **Work** — case studies with real screenshots, a task → solution → result story and a gallery with a lightbox
- **Reviews, process and FAQ** for clients; **experience, toolbox and PDF CV** for recruiters
- **Interactive terminal** (`help`, `whoami`, `projects`, `sudo hire violetta`, …)
- **Project / hiring form** delivered by e-mail through FormSubmit, with a mailto fallback
- English, Russian and Greek; dark and light themes; optional UI sounds; reduced-motion support
- SEO metadata, Open Graph image, `sitemap.xml`, `robots.txt` and Vercel Analytics
